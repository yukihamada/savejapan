# SaveJapan

日本のサイバーセキュリティを強化する3つのプロダクト。

## プロダクト

| # | プロダクト | 説明 | ポート |
|---|---|---|---|
| A | SecurityScanner | 中小企業向けWebセキュリティ診断SaaS | 3000 |
| B | PhishGuard Japan | フィッシング訓練プラットフォーム | 3001 |
| C | SaveJapan Academy | セキュリティ教育プラットフォーム | 3002 |

## 起動方法

各プロジェクトディレクトリで:
```bash
npm install
npm run dev
```
